# ⏱️ Interactive Animated Stopwatch

An attractive and interactive Stopwatch web application featuring real-time timing controls, dynamic image transitions, and custom punch animations. Built using **Vanilla JavaScript, Tailwind CSS, and HTML5**.

---

## ✨ Features

- 🎮 **Interactive Punch Control:** Click the punch lever to start and pause the stopwatch with smooth height transitions (`h-30` to `h-10`).
- 🖼️ **Dynamic Image Switching:** Automatically updates character expressions and positions depending on whether the stopwatch is running or paused.
- ⏱️ **Accurate Stopwatch Counting:** Real-time minutes and seconds counter with zero-padded formatting (e.g., `05` instead of `5`).
- 🔄 **Quick Reset:** One-click reset button to immediately clear the stopwatch display and reset the layout back to its initial state.
- 🎨 **Tailwind CSS Styling:** Clean, modern circular stopwatch face design.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS
- **Logic:** Vanilla JavaScript (DOM Manipulation, State Management, `setInterval`)
